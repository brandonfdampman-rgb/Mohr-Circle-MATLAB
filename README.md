Mohr's Circle MATLAB Project

Overview
-The project calculates and plots a Mohr's Circle from given stress inputs

Inputs Used
-σx=50
-σy=-10
-τxy=30

Outputs
-Mohr Circle Plot
-Center (σavg,0)
-Radius of circle

Features
-Interactive user input
-Error handling for invalid values
-Clean graphical output

Tools Used
-MATLAB
